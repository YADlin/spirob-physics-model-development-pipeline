A continuous design, assembled from discrete links.

L is the requested spiral arc length. Straight links span chords, so the assembled length is slightly shorter. Both are reported above.

The spiral behind the design

Derived constants update from your length, tip width and taper inputs.

rin(θ) = a ebθ
rout(θ) = a eb(θ + 2π)
rc(θ) = ½a (E + 1)ebθ

E = e2πb; nominal width d(θ) = a(E − 1)ebθ.

tan(φ/2) = b(E − 1) / [√(1 + b²)(E + 1)]
a = dtip / (E − 1)
L = A(ebq₀ − 1)

A = √(1 + b²) a(E + 1)/(2b); q₀ = ln(1 + L/A)/b.

Joint stiffness & damping

Assumed gains for the discrete joints. Geometry alone does not calibrate these values.

Kᵢ = K₀ / βⱼ3(i−1)
Dᵢ = D₀ / βⱼ3(i−1)

i starts at 1 at the base. j_001 has its own overrides. βⱼ is a user assumption, independent of geometric βg = ebΔθ.
